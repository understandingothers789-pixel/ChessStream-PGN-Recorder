ChessStream now reads visible English game-ending messages, clocks and player names locally. A repeated result message closes the current game and keeps capture ready for a new board. A unique pending final move can be confirmed by the message when all of that move's changed squares remain visible, even if the dialog obscures unrelated squares. This addresses the reported `...d6` waiting forever after White abandoned the game. Hidden destinations and ambiguous move histories remain unresolved.

Clocks are written into PGN as standard `[%clk]` comments using the first captured reading associated with that move. Visible names beside clocks can fill Unknown headers after three consistent scans; stable name changes and clock resets help detect new games. Include the names/clocks in the selected capture area and leave automatic board detection enabled. A tight 64-square crop cannot see external information. Readings are sampled, not exact release times, and missing times or hidden identities are not guessed.

For **You Won / You Lost**, Settings defaults to remembering the account owner's bottom color when recording begins and retaining it across later flips. Choose White, Black, or Unknown explicitly if the stream starts on an already flipped board. Explicit scores, White/Black Won text and a winner matched to observed names take precedence. Aborted games or unidentified winners retain `*` with a note.

The Game library now has a **Moves & variations** viewer. Select a position before an existing move to add legal SAN alternatives, nested lines and comments. Imported variations/comments survive ordinary edits and export. After a result, the default two-minute review window can record observed alternatives from known game positions without changing the played main line or result. Initial-position reviews can still look like a new game; pause during known opening reviews when needed.

**Diagnostics / logs** opens persistent status/error logs and exports a support ZIP containing logs, recent recognition evidence, settings, game states and PGNs, without screenshots. Logs rotate at about 8 MB total. The bundle can include visible names and local folder/region settings.

Validation: 97 automated tests pass locally, including a controlled reconstruction of the reported d6/abandonment case, result boundaries, clock association, identity changes, annotation persistence and viewer navigation. Four actual native Chess.com browser screenshots verify clocks/names, active-board negatives, a game-aborted dialog and a named-winner resignation; measurements are in `docs/context-v1.4.json`. Windows CI separately tests the source suite, portable inference, GUI and launcher before release. This controlled corpus does not establish accuracy on arbitrary streams or Windows capture hardware.

Download **ChessStream-PGN-Recorder-Portable.zip**, extract it into a new writable folder, close the older copy and open **Launch ChessStream.cmd**. No installer, administrator rights or separate Python installation is required. Existing games and screenshots are preserved.
