# ChessStream PGN Recorder v1.6.17

- The live move list now follows PGN order when you use the left and right arrow keys. Moving past the end of a row selects the next ply, and moving before the start selects the previous ply; the reconstructed board follows the selected move.
- Clarified the portable diagnostic launcher: it runs the app with a visible console so startup errors can be read, and the normal app should be closed first.

Download **ChessStream-PGN-Recorder-Portable.zip**, extract it into a writable folder, and launch it. The portable folder includes its own Python runtime. The source ZIP remains available for users with Python and dependencies already installed.
