This update addresses recordings resumed after the video has advanced beyond the saved board. If a clear position stays unmatched, rewound or multi-path ambiguous for the configured timeout (15 seconds by default), ChessStream preserves the existing verified PGN and starts a separate PGN from the displayed position using standard `SetUp` and `FEN` headers. It continues recording forward without fabricating the moves that occurred before the checkpoint. The first legal continuation resolves whose turn it is.

Use **Start PGN from visible FEN** to begin that separate segment immediately, or **Copy visible FEN** to paste the board position into Nibbler or another chess GUI. If the position is not already known in the game history, the copy action asks which side moves and assumes no castling rights or en passant target because those cannot be seen in a screenshot. A clear single-ply move waiting for the opponent remains provisional and is intentionally excluded from automatic recovery, protecting the held-piece behavior introduced in v1.2.

Validation: all source tests pass, including recovery timeout, preservation of the old PGN, checkpoint FEN/SetUp export, screenshot association, side-to-move inference from later play, cancellation when the board changes or returns to the saved state, and clipboard selection of an explicit side to move. Windows CI validates the portable runtime and GUI before publishing the release.

Download **ChessStream-PGN-Recorder-Portable.zip** below, extract it into a writable folder, and open **Launch ChessStream.cmd**. The portable package needs no installer, administrator rights or separately installed Python. Existing games and screenshots are preserved.
