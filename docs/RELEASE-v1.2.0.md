This update addresses a recording stalled after `Bb6`, where the direct `Ng5 Nh6 Qf3` continuation competed with unverified bishop detours. The recorder now rechecks shorter legal evidence from the verified board, preserves equal-depth ambiguity, and requires positive evidence on changed squares. It never silently rewrites verified moves.

**Held-piece protection is now on by default.** The newest move stays provisional in amber until the opponent replies. Holding a bishop over `c5` for several seconds cannot verify `Bc5`; moving it to `b4` before release can replace that candidate. At the end of a game, review the last move and click **Confirm final / pending move** before exporting. Checkmate also needs this final confirmation if no reply follows. Stopping, exporting and restarting do not promote a pending move automatically. This deliberately keeps the verified board and PGN one ply behind during play.

**Screenshots now default to Per position.** Repeated captures of the same recognized placement in the same game do not save extra PNGs, including arrow/cursor changes that preserve that placement. Recognition continues between saved images. A provisional hover may still be saved for review; a repeated position after intervening moves is saved again. Existing screenshots are kept, and automatic deletion remains off. Choose **At interval** to restore timed screenshots.

Validation includes native Chess.com blue arrows over the reported continuation, an actual held drag over `c5` followed by release at `b4`, a controlled five-second legal-hover test, pending-state crash recovery, PGN export, screenshot retention, and a headed browser/MSS capture test. The latter processed 54 updates and saved five images, with seven of eight plies automatically verified and one explicit final confirmation. Evaluation reports count that intervention. These controlled results do not establish accuracy on arbitrary streams or heavy overlays. Physical Windows capture/scaling still needs checking on your PC.

Download **ChessStream-PGN-Recorder-Portable.zip**, extract it into a new folder, close the older copy and open **Launch ChessStream.cmd**. No installer, administrator rights or separate Python installation is required; the ZIP contains a private Python runtime. Existing data in the default data folder remains available. Old incorrect verified moves need manual correction rather than being silently changed by an update.
