# ChessStream PGN Recorder v1.6.15

- Click a live move-list cell to review the position after that move on the reconstructed board. Keep it pinned during continued capture, with a labeled Return to live board button. Return automatically when the active game changes or the selected move prefix is replaced. Support Black-to-move FEN roots and pending move previews without changing the recorded PGN.
- Add the default-enabled Switch to unrelated positions setting. After the configured stable new-game delay, check earlier played positions and bounded legal branches up to six plies, then preserve the old recording and start a new PGN for an unlinked clear board. This runs before the rewind guard so an unrelated position cannot remain trapped there indefinitely. Earlier branch matches are remembered so the shorter fallback search cannot undo that decision.
- Let the longer opening bootstrap tolerate up to two weak unchanged starting squares, with original-label support and no inferred move touching them. This handles the reported weak b1 reading without silently assuming a moved piece. Use opening inference when supported and a visible FEN otherwise.

Validation: 67 local tests passed, followed by focused transition/recording checks after the final branch-link refinement. New cases cover pinned click review, updates while reviewing, return to live, game switches, Black-to-move FENs, unrelated midgame replacement while rewind is latched, the setting disabled, a known analysis branch several plies from an earlier anchor, and the supplied opening with weak b1 evidence. The reported board geometry was reconstructed for controlled tests; the exact video/capture sequence was not replayed. Tagged Windows CI builds and validates the portable package.

Limits: bounded search failure is not a proof of mathematical impossibility. An unseen analysis board with no connection found within the available budget can still be classified as a new game. The general split requires a clear valid board; temporary obstruction and uncertain moved squares can still delay it. The previous PGN is preserved and existing automatic/manual joining remains available.
